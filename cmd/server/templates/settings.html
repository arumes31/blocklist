Source Adapters

Fail2ban

Configure Fail2ban to push bans to this app. Add an action file /etc/fail2ban/action.d/blocklist.conf: 

[Definition]
actionban = curl -X POST -H "Authorization: Bearer YOUR_TOKEN" -H "Content-Type: application/json" -d '{"ip":"<ip>","act":"ban","reason":"fail2ban-<name>","ttl":86400}' {{ .base_url }}/api/v1/webhook
actionunban = curl -X POST -H "Authorization: Bearer YOUR_TOKEN" -H "Content-Type: application/json" -d '{"ip":"<ip>","act":"unban"}' {{ .base_url }}/api/v1/webhook

Note: Bans default to 24h (86400s) if persist is false and ttl is omitted.

Examples

Authentication Note

Most API endpoints require Bearer Tokens. Standard Basic Authentication (username:password) is supported only as a fallback for the Whitelist APIs.

Curl Examples

List Blocked IPs (JSON) [Authenticated, view_ips]

curl -H "Authorization: Bearer YOUR_TOKEN" \
     {{ .base_url }}/api/v1/ips_list

List Whitelisted IPs (JSON) [Authenticated, view_ips]

# Bearer Token
curl -H "Authorization: Bearer YOUR_TOKEN" {{ .base_url }}/api/v1/whitelists

# Basic Auth Fallback
curl -u admin:password {{ .base_url }}/api/v1/whitelists

List Whitelisted IPs (Raw Text) [Authenticated, view_ips]

# Bearer Token
curl -H "Authorization: Bearer YOUR_TOKEN" {{ .base_url }}/api/v1/whitelists-raw

# Basic Auth Fallback
curl -u admin:password {{ .base_url }}/api/v1/whitelists-raw

Block an IP (Webhook style, 1h TTL) [Authenticated, block_ips]

curl -X POST {{ .base_url }}/api/v1/webhook \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"ip": "1.2.3.4", "act": "ban", "reason": "manual", "ttl": 3600}'

Unblock an IP (Webhook style) [Authenticated, unblock_ips]

curl -X POST {{ .base_url }}/api/v1/webhook \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"ip": "1.2.3.4", "act": "unban"}'

Add IP to Whitelist (Webhook style) [Authenticated, whitelist_ips]

curl -X POST {{ .base_url }}/api/v1/webhook \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"ip": "1.2.3.4", "act": "whitelist", "reason": "trusted service"}'

Wget Examples

Download Blocklist (TXT) [Authenticated, export_data, Sudo]

wget --header="Authorization: Bearer YOUR_TOKEN" \
     {{ .base_url }}/api/v1/ips/export?format=txt \
     -O blocklist.txt

Download Whitelist (JSON) [Authenticated, view_ips]

wget --header="Authorization: Bearer YOUR_TOKEN" \
     {{ .base_url }}/api/v1/whitelists \
     -O whitelist.json

Download Whitelist (Raw Text) [Authenticated, view_ips]

wget --header="Authorization: Bearer YOUR_TOKEN" \
     {{ .base_url }}/api/v1/whitelists-raw \
     -O whitelist.txt

Block an IP (POST) [Authenticated, block_ips]

wget --header="Authorization: Bearer YOUR_TOKEN" \
     --header="Content-Type: application/json" \
     --post-data='{"ip":"1.2.3.4","act":"ban"}' \
     {{ .base_url }}/api/v1/webhook -O -

Unblock an IP (POST) [Authenticated, unblock_ips]

wget --header="Authorization: Bearer YOUR_TOKEN" \
     --header="Content-Type: application/json" \
     --post-data='{"ip":"1.2.3.4","act":"unban"}' \
     {{ .base_url }}/api/v1/webhook -O -

Add IP to Whitelist (POST) [Authenticated, whitelist_ips]

wget --header="Authorization: Bearer YOUR_TOKEN" \
     --header="Content-Type: application/json" \
     --post-data='{"ip":"1.2.3.4","act":"whitelist","reason":"trusted"}' \
     {{ .base_url }}/api/v1/webhook -O -
