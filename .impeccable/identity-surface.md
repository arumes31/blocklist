# Identity and activity extension

Mode: Operate. Extend the incumbent charcoal workspace, not a replacement design world.

Login keeps the original animated raster wordmark and radial particle field. Motion thesis: a slow, red-toned current around an always-visible, stable sign-in panel; pause when hidden and stop under reduced motion. A visible pause control governs decorative animation. Local credentials/TOTP remain available alongside configured Microsoft sign-in.

Roles use a list/detail editor with grouped, explicitly named permissions. Accounts distinguish local credentials from immutable Entra tenant/object bindings. Read-only roles see information without write controls. System audit and IP event history each have a dedicated navigation destination and category-scoped filters.

Default roles: Viewer reads all metadata (never secrets); Moderator additionally creates whitelist entries and exclusions and unblocks; Editor manages all. Preserve existing legacy permission snapshots until an explicit role assignment.

## Direction contract

THESIS: Keep the operational workspace calm while making identity and activity boundaries explicit. Avoid turning the role editor into a wall of settings cards.

OWN-WORLD: Inherit the existing charcoal surfaces, flat bordered regions, system sans, and restrained red enforcement accent. Restore the supplied animated APNG wordmark rather than inventing a new brand.

STORY: Sign in locally or through configured Microsoft identity; inspect a role's exact capabilities; assign accounts; find system changes separately from IP events.

FIRST VIEWPORT: Desktop login pairs a 270px original logo and quiet particle current on the left with a 420px form on the right. Mobile stacks a compact logo and the same form. Roles pair a compact list with a grouped permission editor; accounts lead with a collapsible creation form and metadata table.

FORM: User-assigned extension of the incumbent Operate world; no new-world roll or seed. Signature interaction: an always-visible login panel against pausable, reduced-motion-aware radial particles.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
